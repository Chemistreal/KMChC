## ② report-data/ — 손대지 않았다

| | |
|---|---|
| 파일 | 58장 |
| 이름이 실린 장 | 56장 |
| 사람 | **53명** |

한 장의 속:

```json
{ "id": "r05540dd302614314", "name": "홍길동", "grade": "중2",
  "answers": "eyJWLU9DIjpbMCwx…", "savedAt": "2026-06-11T09:09:52.164Z" }
```

*(이름 칸만 예시로 바꿔 적었다. 이 문서도 공개 저장소에 있어서, 실제 이름을
적으면 그 이름이 여기서 새기 때문이다 — 실제로 자한테 한 번 잡혔다.)*

**이건 지우면 안 된다.** 학부모에게 간 링크가 `report.html?id=…` 이고,
그 화면이 여는 것이 바로 이 파일이다. 지우면 **이미 보낸 리포트가 그 자리에서
깨진다.** 그래서 [`tools/public_names.py`](../tools/public_names.py) 는 여기를
막지 않고, 적어 두기만 한다.

그리고 이건 사고가 아니라 **설계가 그렇다.** Apps Script 가 저장할 때마다
여기에 한 장씩 넣는다(`AppsScript_GitHub빠른조회_정리본.gs` 의
`REPORT_DATA_DIR`). 6월 11일부터 7월 26일까지 여섯 주에 58장 — 학생이 검사를
볼 때마다 실명이 한 장씩 공개 저장소에 쌓인다.

### 고칠 방법은 이미 절반 놓여 있다

`report.html` 을 열어 보니 주소에서 이름을 받게 되어 있다.

```js
var id=p.get("id")||"", d=p.get("d")||"", nm=p.get("n")||"", gr=p.get("g")||"";
…
function render(ans,name,grade){ setLinks(name||nm, grade||gr); … }
```

`name||nm` — **파일에 이름이 없으면 주소의 이름으로 넘어간다.** 그러니

* Apps Script 가 `name` · `grade` 를 파일에 **안 넣고** (시트에는 그대로 둔다)
* 링크를 `report.html?id=…&n=<이름>` 로 만들면

공개 파일에는 **익명 응답만** 남고, 이름은 **링크를 쥔 사람만** 본다.
`report.html` 은 한 줄도 안 고쳐도 된다.

## ③ 선생님이 정하실 것

| | 물음 | 손대면 | 안 손대면 |
|---|---|---|---|
| **가** ✅ | 앞으로 저장되는 것부터 이름을 파일에서 빼고 링크에 실을까 | Apps Script 와 링크 만드는 곳 두 군데. 화면은 안 고친다 | 검사를 볼 때마다 실명이 한 장씩 더 쌓인다 |
| **나** | 이미 있는 58장에서도 이름을 뺄까 | 옛 링크는 `&n=` 없이 나갔으므로 **그 리포트들만 이름을 잃는다**(내용·유형은 그대로) | 쉰세 명의 이름이 공개된 채로 남는다 |
| **다** | 지난 기록(git history)에서도 지울까 | 역사를 다시 쓰고 강제로 민다. **되돌릴 수 없다.** 열아홉 명 + 쉰세 명이 사라진다 | HEAD 에서 지워도 커밋을 뒤지면 읽힌다 |
| **라** | 저장소를 비공개로 돌릴까 | GitHub Pages 는 비공개 저장소에서 유료 요금제가 필요하다 | 지금대로 |

## 재는 자의 한계

`"name"` · `"n"` · `"이름"` 같은 **자료 칸에 든 값만** 본다. 문장 속에 적힌
이름은 못 본다. 재는 것과 막는 것은 다르다.

자를 만들면서 **세 번** 틀렸다. 규칙에 관한 두 가지는
[`tools/lie_check.py`](../tools/lie_check.py) 에 예시로 박아 두었다.

1. *'…성 · …율 로 끝나면 화학 용어'* 로 걸렀더니 그렇게 끝나는 **학생 넷**이
   통째로 안 보였다. 쉰셋이 마흔아홉으로 줄었다.
   실명을 세는 자가 실명을 못 보면 **없는 것보다 나쁘다** — 세었다는 안심만 준다.
2. 값 **전체**가 이름일 때만 셌더니, 이름 뒤에 괄호를 단 한 장이 숨었다.
   같은 반에 같은 이름이 둘이라 손으로 갈라 적어 두신 것인데, **갈라 적을
   만큼 신경 쓴 이름일수록 자한테서 숨는** 꼴이었다.

그리고 이 자는 **제 것부터 잡았다.** 검사 예시에 실제 학생 이름을 썼을 때
한 번, 그 까닭을 적은 주석에서 또 한 번, 이 문서의 예시 JSON 에서 또 한 번.
셋 다 맞게 잡았다 — 실명이 새는 것을 막는 자가 새는 자리가 되면 안 된다.

그때 **손에서는 초록인데 커밋하자마자 판이 빨간불**이었다. 자가
`git ls-files --cached` 만 보아 **아직 담지 않은 새 파일**을 못 봤기 때문이다.
`--others` 를 같이 보게 고쳤다.

그리고 처음 잰 값은 **0곳**이었다. `git ls-files` 가 한글 이름을
`"\352\264\200…"` 로 내주는 것을 몰라서, 이 저장소에서 이름이 가장 많이 실린
화면이 통째로 검사에서 빠져 있었다. **자가 못 본 것과 거기 없는 것은 다르다.**
